# 📸 Raghuveer Photography

A modern and responsive photography portfolio website built using **Next.js**, **TypeScript**, and **Tailwind CSS**.

🌐 **Live Demo:**  
https://raghuveer-photography.vercel.app

---

## 📌 Overview

This website was developed for a professional photographer to showcase photography services, galleries, and contact information through a clean and responsive user interface.

## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/meghana-1703/raghuveer-photography.git
```

Navigate to the project folder

```bash
cd raghuveer-photography
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

Visit:

```
http://localhost:3000
```
